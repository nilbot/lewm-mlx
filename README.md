# Le World Model in MLX (lewm-mlx)

This repository is a native **MLX** port of the **LeWorldModel (LeWM)** architecture for efficient Joint-Embedding Predictive Architectures on Apple Silicon (macOS).

## Installation

```bash
uv pip install -e .
```

## Running tests

```bash
PYTHONPATH=. uv run pytest tests/test_comparison.py
```
